创建你的第一个Skill

2026-10-22
14k- 28 分钟-
技术笔记-MCPChrome DevToolsTraeCodePicGoAI工作流

前言

这两年AI发展十分火爆，我也在思考有没有什么可以用得上并且可以练手的项目。由于我的blog一直是先通过写在石墨文档上，再抽时间转成本地markdown文档调整格式，再上传到服务器。虽然石墨文档可以直接下载为markdown文件，但会导致有些图片无法显示，以及大于3M的文档无法导出。于是笔者有了刚好把这一套流程编写成一个Skill的想法，顺便熟悉和了解一下MCP的使用。在操作过程中了解到其实有一个github的开源项目rush-shimo-cli（https://github.com/kanyun-inc/rush-shimo-cli）可以直接提取石墨文档内容，但本文还是以Chrome MCP为例，后续再通过tokens的使用速度以及操作流程的便利性考虑是否进行优化。

梳理流程

  1. 通过 Chrome 浏览器打开指定网页（复用已登录的 Chrome 账号，可能用 Chrome MCP）
  2. 把网页文字和图片转换成规定格式的 .md 文件并保存
  3. 图片先通过 PicGo 上传到图床，再以网络图片 URL 写入 MD
  4. 保存并提炼为 Skill

这里我们使用TraeCode进行整个流程的操作。

浏览器抓取

第一步 启动Chrome远程调试

这是让 MCP 能“看到”已登录 Chrome 的前提。在 Chrome 地址栏输入：

chrome://inspect/#remote-debugging

第二步 在 TraeCode 中添加 MCP 服务器

打开 TraeCode 设置 → MCP → 添加服务器。推荐直接从市场搜索 “Chrome DevTools” 添加；
